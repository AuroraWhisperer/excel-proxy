# Excel Proxy 使用说明

## 这个程序做什么

它让 Codex 使用你在 Excel 的 ChatGPT 加载项里已经登录的账号。

你仍然在 Codex 里提问、看回复、让它处理项目。Excel Proxy 在背后转发请求，不需要你每次把问题复制到 Excel。程序本身不会执行模型要求的命令；文件和命令工具由 Codex 执行。

它不会替你购买套餐，也不能解锁账号原本不能用的模型。实际可用的模型和次数由 Excel 后端决定。

## 第一次准备

需要有 Python 3.11 或更新版本、Excel 桌面版，以及已经登录的官方 ChatGPT 加载项。Windows 独立窗口还需要 WebView2 Runtime；本机目前的启动方式就是使用它。

如果当前项目已经能双击启动，跳过安装步骤即可。

在 Windows 中，打开项目文件夹里的 PowerShell，执行一次：

```powershell
py -3 -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
```

完成后双击 **启动.vbs**。

macOS 用户可在项目目录执行：

```bash
bash tools/install_macos.sh
./.venv/bin/python -B app/proxy.py
```

再打开[本地控制面板](http://127.0.0.1:8000/)。macOS 从 Excel 的本地存储读取登录会话，没有 Windows 的双击窗口入口。

## 连接 Codex

1. 在 Excel 中打开 ChatGPT 加载项并登录。如果登录过期，先在加载项内重新登录或刷新。
2. 打开 Excel Proxy，点 **读取 Excel 会话**。页面显示“会话已就绪”后继续。
3. 选择要测试的模型，点 **测试连接**。这会真正发送一条短请求，消耗少量账号额度；不会自动执行。
4. 展开 **Codex 与启动设置**，点 **启用接入**。程序会先备份原配置。
5. 重启 Codex，建议开一个新对话进行使用。

“测试连接”成功说明当时这个账号和模型可以完成短文本回复。它不代表所有工具、图片或长任务都一定成功。

已经接入过时，按钮会显示 **更新模型列表**。更新代理后点一次，再重启 Codex，让它读取新的模型设置。

## 平时启动和退出

双击 **启动.vbs** 打开窗口。重复双击会唤起现有窗口，不会另外启动一份服务。最小化后代理继续工作；关闭窗口右上角的 **×** 才会退出。

默认勾选 **关闭代理时恢复原配置**：退出时恢复 Codex 原配置，下次启动代理再接入。你也可以随时点 **恢复原配置** 撤销接入，再重启 Codex。

修改源码或更新文件后，要等正在执行的任务结束，再关闭旧代理、重新启动。只重复双击启动器，仍然打开的是旧进程。

## 窗口里的数字是什么意思

**API 费用估算**是把经过这个代理的文本请求量，按程序里的参考单价换算成美元，帮助你了解大概用了多少。它不是实际账单，不是 Excel 的剩余额度，参考价格也不保证是最新报价。

**最近请求**在独立页面里，可以看请求时间、模型、耗时和结果。列表最多展示最近 100 条；这不等于程序只保存或统计 100 条。

想查看新请求的全文，可以在设置里打开 **记录请求全文**。默认关闭。打开后，提示词等内容会保存在本机，排查完可以关掉；之前没有记录的全文无法补回来。

## 看图和生图

可以把图片交给模型理解，也可以在客户端提供对应工具时生成或编辑图片。这两种操作走不同接口。

看图时，普通消息里的内嵌图片会上传到 OpenAI 的 Excel 附件接口，再用附件编号提问；工具返回的截图仍保留内嵌形式。同一账号的相同图片会尽量复用已上传的附件。

看图请求接受 PNG、JPEG、GIF、WebP 的 base64 数据。每张最多 20 MiB，每个请求最多 20 张，内嵌图片合计最多 32 MiB；历史里一起带回的图片也计入。格式或大小不合适会明确报错，不会把图片丢掉后继续回答。这里检查的是声明的格式、编码和大小，图片内容最终仍由上游解析。

生成和编辑图片使用 Excel 的图片接口，可能消耗账号额度。当前文本 token 统计不包含这部分图片费用。接口的具体限制见[开发说明](开发说明.md)。

## 常见问题

| 看到的情况 | 可以怎么做 |
| --- | --- |
| 未找到会话、会话过期或 401 | 在 Excel 的 ChatGPT 加载项内登录或刷新，再点“读取 Excel 会话”。 |
| 模型没有权限，或上游返回 403 | 换一个该 Excel 账号能使用的模型。代理不会偷偷换账号或模型。 |
| 本地返回 `local_access_required` | 从本机控制面板打开；不要通过其他网站、嵌入页面或局域网地址调用。 |
| 429 | 上游限流，等一会儿再试。 |
| 图片太大、太多或格式不支持 | 压缩图片、减少本次携带的图片，或转成支持的格式。 |
| 工具无法转换、连接中断 | 先确认已重启新版代理和 Codex；仍然出现时，保留错误代码和请求时间。 |
| 一直没有回复 | 查看“最近请求”是否仍在执行或已失败；流开始后代理不会擅自重放整条请求。 |
| 双击后启动失败 | 查看弹窗及 `%LOCALAPPDATA%\ghcp_proxy\ghcp-proxy.stderr.log`。 |

如果收到的是“请求必须是 JSON 对象”，通常是调用程序传错了格式。例如应发送 `{"input":"你好"}`，不能只发送一个数组或数字。

## 数据放在哪里

Windows 下：

- 设置：`%APPDATA%\ghcp_proxy`。
- 会话、用量、日志和工具历史：`%LOCALAPPDATA%\ghcp_proxy`。
- Codex 原配置和备份：用户目录下的 `.codex`。

Windows 会话使用系统加密保存，macOS 的代理会话只留在内存。点 **清除缓存** 清除的是代理保存的登录会话，不会让 Excel 退出登录；Excel 仍登录时，后续读取可以再次找到它。

为了让工具任务在重启后继续，程序还会保存工具调用历史，其中可能有文件名、命令和代码参数。这与“记录请求全文”开关是两回事，不能把“关闭全文记录”理解为本机完全不保存任务内容。

程序只供本机使用。请求和图片会发往 Excel / OpenAI 后端；本地入口会检查连接来源和浏览器来源，拒绝外部网页直接调用。
