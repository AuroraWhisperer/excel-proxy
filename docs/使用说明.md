# Excel 连接服务 使用说明

[项目首页](../readme.zh-CN.md) · [English](../readme.md) · [文档目录](README.md)

## 这个程序做什么

它让 Codex 使用 OpenAI Excel/BPS 后端。Windows 可以直接在软件中发起官方登录、保存多个账号并手动切换，不需要打开 Excel。

你仍然在 Codex 里提问、看回复、让它处理项目。Excel 连接服务在背后转发请求，不需要你每次把问题复制到 Excel。程序本身不会执行模型要求的命令；文件和命令工具由 Codex 执行。

使用前需自行开通所需套餐。实际可用的模型和次数由 Excel 后端的账号权限与额度决定。

## 第一次准备

需要 Git、Python 3.11 或更新版本、Codex，以及可访问 Excel/BPS 的 OpenAI 账号。Windows 独立窗口需要 WebView2 Runtime，官方登录窗口需要 Edge 或 Chrome。只有使用 Excel 缓存兼容入口时才需要 Excel 桌面版和已登录的官方加载项。

如果当前项目已经能双击启动，跳过安装步骤即可。

### Windows

在 PowerShell 中下载项目并安装依赖；已有项目文件夹时，从创建虚拟环境这一步开始：

```powershell
git clone https://github.com/AuroraWhisperer/excel-proxy.git
cd excel-proxy
py -3 -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
```

完成后双击 **启动.vbs**。

### macOS

先在 OpenAI Excel 加载项中登录，再下载项目并安装：

```bash
git clone https://github.com/AuroraWhisperer/excel-proxy.git
cd excel-proxy
bash tools/install_macos.sh
./.venv/bin/python -B app/proxy.py
```

打开[本地控制面板](http://127.0.0.1:8000/)，在 **高级设置 → 使用 Excel 登录** 中点击 **读取 Excel 登录**，再点击 **启用接入**。首次接入后重启 Codex。

macOS 从 Excel 的本地存储读取登录会话，没有 Windows 的双击窗口入口。直接登录与账号凭据加密保存目前仅支持 Windows。

## 连接 Codex

Windows 直接登录：

1. 打开 Excel 连接服务，点 **登录并连接**，在官方窗口完成账号登录和验证码。
2. 授权后自动验证 Excel/BPS 模型，消耗少量额度；成功才切换账号并自动配置 Codex，原配置会备份。
3. 首次接入后重启 Codex，开一个新对话使用。
4. 点 **添加账号** 可保存更多账号，选择后点 **使用此账号**。移除当前账号会停止使用，不会自动改用别的账号。

macOS 或需要 Excel 缓存的用户，可展开 **高级设置 → 使用 Excel 登录** 读取已登录的加载项会话，再手动启用 Codex 接入。直接登录的详细行为和存储说明见[直接登录与多账号](direct-login.md)。

“测试连接”成功说明当时这个账号和模型可以完成短文本回复。它不代表所有工具、图片或长任务都一定成功。

登录验证成功时会自动更新模型目录；需要手动更新或恢复原配置时，使用 **高级设置 → Codex 配置**。

## 平时启动和退出

Windows 下双击 **启动.vbs** 打开窗口。重复双击会唤起现有窗口，不会另外启动一份服务。最小化后服务继续工作；关闭窗口右上角的 **×** 才会退出。macOS 在终端运行 `./.venv/bin/python -B app/proxy.py`，按 `Ctrl+C` 停止服务。

## 更新与恢复配置

更新前，等待正在执行的任务结束并关闭服务，然后在项目目录执行：

```powershell
git pull --ff-only
./.venv/Scripts/python.exe -m pip install -r requirements.txt
```

macOS 的依赖安装命令使用 `./.venv/bin/python`。完成后重新启动服务；旧进程未退出时，仅再次双击启动器不会加载新代码。

如果要撤销接入，在 **高级设置 → Codex 配置** 中点击 **恢复原配置**，然后重启 Codex。默认开启的 **关闭服务时恢复原配置**也会在退出服务时恢复，下次启动时重新接入。

## 窗口里的数字是什么意思

**API 费用估算**是把经过这个服务的文本请求量，按程序里的参考单价换算成美元，帮助你了解大概用了多少。它不是实际账单，不是 Excel 的剩余额度，参考价格也不保证是最新报价。账号额度、统计周期和重置卡的说明见[账号额度](account-balances.md)。

**最近请求**在独立页面里，可以看请求时间、模型、耗时和结果。列表最多展示最近 100 条；这不等于程序只保存或统计 100 条。

想查看新请求的全文，可以在设置里打开 **记录请求全文**，默认关闭；日志与工具历史的保存范围见[隐私与本地数据](privacy.md#请求日志与工具历史)。

## 看图和生图

可以把图片交给模型理解，也可以在客户端提供对应工具时生成或编辑图片。这两种操作走不同接口。

看图接受内嵌图片，格式或大小不合适会明确报错；历史里一起带回的图片也计入限制。生成和编辑图片可能消耗账号额度，当前文本 token 统计不包含图片费用。支持的格式、数量和接口参数见 [API 与兼容范围](api.md#图片输入)。

## 常见问题

| 看到的情况 | 可以怎么做 |
| --- | --- |
| 未找到会话、会话过期或 401 | 直接登录账号请重新登录；已保存账号时按钮显示为“添加账号”。仅使用 Excel 缓存会话时，才需在加载项内登录或刷新，再点“读取 Excel 登录”。 |
| 模型没有权限，或上游返回 403 | 换一个该 Excel 账号能使用的模型。服务不会偷偷换账号或模型。 |
| 本地返回 `local_access_required` | 在本机通过 `http://127.0.0.1:8000/` 打开控制面板；不要通过其他网站、嵌入页面或局域网地址调用。 |
| 429 | 上游限流，等一会儿再试。 |
| 图片太大、太多或格式不支持 | 压缩图片、减少本次携带的图片，或转成支持的格式。 |
| 工具无法转换、连接中断 | 先确认已重启新版服务和 Codex；仍然出现时，保留错误代码和请求时间。 |
| 一直没有回复 | 查看“最近请求”是否仍在执行或已失败；流开始后服务不会擅自重放整条请求。 |
| 双击后启动失败 | 查看弹窗及 `%LOCALAPPDATA%\ghcp_proxy\ghcp-proxy.stderr.log`。 |

如果收到的是“请求必须是 JSON 对象”，通常是调用程序传错了格式。例如应发送 `{"input":"你好"}`，不能只发送一个数组或数字。

Windows 下需要查看控制台输出时，先关闭桌面窗口，再在项目目录运行：

```powershell
./.venv/Scripts/python.exe -B app/proxy.py
```

仍无法解决时，可[提交 Issue](https://github.com/AuroraWhisperer/excel-proxy/issues)，附上系统、启动方式、错误代码和请求时间；不要附带真实凭据或未经处理的请求全文。

## 数据放在哪里

设置和历史保存在项目目录之外。各平台路径、凭据加密、请求日志、工具历史，以及移除账号和清除缓存的区别，统一见[隐私与本地数据](privacy.md)。
