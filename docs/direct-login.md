# 直接登录与多账号

Windows 首页的 **登录并启用代理** 使用 ChatGPT 官方授权窗口，不需要启动或模拟 Excel。它复用已有 PKCE S256、随机 state、本机回调和独立浏览器生命周期；密码、验证码只输入官方页面。Excel/BPS 是兼容接入路径，登录成功不代表账号具备所选模型权限，服务方的权限和额度限制继续生效。

## 日常使用

- 首次登录自动保存账号，发送一次简短模型请求验证，成功后启用该账号、备份原 Codex 配置并写入代理配置/模型目录。首次接入后请重启 Codex。
- 添加账号会保留原账号；新账号验证成功才成为当前账号。验证失败时仍保留候选账号，用户可在高级设置更换测试模型后手动重试。
- 最多保存 50 个账号。选择器中的 **切换并启用** 只影响随后开始的请求，已开始的请求保留自己的身份。不会在 401、403 或额度不足时自动换账号。
- 同一账号重新登录会暂存新凭据，验证前不替换正在使用的凭据。删除当前账号会停止使用，重启后也不会回退到旧 Excel 缓存。
- 账号已启用且凭据未变化时，重复的启用请求不会重复消费验证额度。高级设置中的手动测试仍可重新验证当前模型。
- 登录或验证成功后关闭页面不会删除账号。若离开页面时授权刚完成、尚未自动验证，可返回后手动选中已保存账号启用。

## 账密自动登录与 JSON 文件

首页和用量页均提供 **账密自动登录**。粘贴一行 `账号----密码---2FA密钥` 后，程序打开独立无痕会话，依次填写账号、密码，访问 [2fa.fun](https://2fa.fun/) 获取验证码并提交。第三项是 Base32 密钥，不是六位临时验证码；支持三连字符、四连字符及混合分隔，以第一段和最后一段连续三个以上连字符作为分隔符，密码中间的连字符会保留。每次登录一个账号。

密码和密钥只用于本次流程，不写入账号文件或登录日志；2FA 密钥会按此功能的约定交给 2fa.fun，账号和密码只填入 OpenAI 官方登录页面。网站布局变化、人机验证、邮件验证码、工作空间选择或授权确认需要在窗口里手动继续。不会自动选择工作空间或重复提交被拒绝的凭据；成功、取消或超时后会关闭本次窗口。

自动登录与手动登录复用同一个本机浏览器启动器，明确打开 Edge InPrivate 或 Chrome Incognito 独立窗口；项目虚拟环境中的 Playwright 通过本机临时端口连接该窗口填写表单，不再另外启动测试浏览器。每次使用独立临时用户目录，结束后关闭本次进程并清理目录。更新后需安装 `requirements.txt` 中的依赖，不需要下载额外浏览器。用量页的 **导入 JSON** 继续直接读取原有账号 JSON 文件，不走账密自动填写；首页登录成功后仍按原流程验证并启用代理，用量页登录仅添加额度查询账号。

## 凭据与续期

代理账号存于配置目录的 `proxy-accounts.dpapi`，使用当前 Windows 用户的 DPAPI 加密并原子替换。保存 access token、授权服务器返回的 refresh token、有效期和明确选择的账号；不保存密码、验证码、ID token。公开状态只返回邮箱、脱敏账号提示、有效期和状态，不返回任何 token。

直接登录额外申请 `offline_access`，凭据临近到期时按需续期；并发请求共用一次刷新。刷新令牌轮换后加密保存新值，未返回新刷新令牌时保留旧值。永久授权失败标记为需要重新登录；暂时网络失败保留凭据以便重试。续期校验账号身份，不能把返回的其他账号静默安装进来。

访问令牌也可能在标记的到期时间之前被服务端撤销。Responses 初始请求或前置图片上传明确返回 HTTP 401 时，代理只对被拒绝的同一已选账号续期，并最多重发一次；并发的旧令牌 401 复用已刷新的凭据，不重复轮换。不会取用待验证的新登录、切换账号或回退 Excel 缓存。刷新本身返回永久授权失败时，账号立即显示需要重新登录。若账号在刷新过程中切换，则保留原账号的新凭据但停止重发。上游已经接受生成后，纠错请求的 401 不会触发整轮重发；403、429、5xx 和读写中断也不触发此认证重试。新登录的验证请求始终验证原来的候选凭据。

新账号成功启用时，仅将 access token 同步给原有余额查询账号库。余额查询库仍不持有 refresh token；它和代理账号库的删除操作相互独立。余额查询自身的缓存、过期处理仍遵循原有规则。

## 高级兼容入口

读取 Excel 缓存是显式切换登录来源的兼容操作。直接账号模式下，启动和发送请求不会强制读取或覆盖为 Excel 会话。清除旧 Excel 缓存不等于退出直接登录账号；请使用账号管理中的移除操作。

## 实现与验证

- `app/account_login.py`：复用官方授权生命周期，余额登录与代理登录使用不同的保存目标。
- `app/proxy_accounts.py`：加密账号库、暂存重登录凭据、明确选择与单次并发刷新。
- `app/proxy.py`：本机账号 API、真实模型验证、自动配置，以及 Responses/图片请求的按次凭据选择。
- `tests/test_proxy_accounts.py`：多账号、续期、重登录隔离、失败回滚、本机访问限制和持久化回归。

开发测试使用隔离目录、模拟官方授权/模型响应和禁止真实 HTTP 的离线运行器。浏览器测试不等同于真实账号权限验证；真实官方登录、续期及模型调用需要用户在应用中验收。不要把真实凭据或登录响应写入 Git、日志或截图。
