# 开发说明

日常操作请先看[使用说明](使用说明.md)。这份文档用于查找代码、维护接口和运行测试。

## 文件放在哪里

| 位置 | 负责什么 |
| --- | --- |
| `启动.vbs` | Windows 双击入口，调用项目自己的 Python 环境。 |
| `app/windows_launcher.py` | 创建独立窗口、唤起已有窗口、退出时关闭服务。 |
| `app/proxy.py` | HTTP 路由、请求生命周期、流式转发和使用记录。 |
| `app/local_access.py` | 本机连接、Host 和浏览器来源检查。 |
| `app/excel_upstream.py` | Excel 请求转换、工具目录、工具调用转换与历史重放。 |
| `app/excel_stream.py` | 流式保活和有条件的完成事件恢复。 |
| `app/excel_images.py` | 看图请求的检查、附件上传和缓存。 |
| `app/excel_image_generation.py` | 生图和图片编辑的请求、结果校验。 |
| `app/excel_session_capture.py` | 从本机 Excel 加载项缓存读取已登录会话。 |
| `app/proxy_client_config.py` | Codex 配置、原配置备份与恢复。 |
| `app/dashboard.py`、`app/usage_tracking.py` | 请求历史、用量和费用估算。 |
| `app/static/` | 首页、最近请求页和共用样式。 |
| `app/prompts/` | Codex 基础提示词。 |
| `tests/` | 离线回归测试。 |
| `tools/` | 安装、测试、首字延迟和缓存诊断脚本。 |
| `docs/archive/` | 历史排查记录；`plans/` 内保存实施计划。 |

现有源码已经按程序、测试和脚本分开，本次保留模块路径。`.venv/` 是运行环境，`.tmp/` 和 `__pycache__/` 是本地工作文件，均不提交。旧临时目录可能被其他工作使用，本次未批量删除。

`tools/probe-first-output.py` 会真正发送请求，仅在需要测上游延迟时手动运行。`tools/test-proxy-contracts.py` 是离线测试，两者用途不同。

## 启动和验证

在仓库根目录运行，Windows：

```powershell
./.venv/Scripts/python.exe -B app/proxy.py
```

离线回归使用隔离的设置、状态和缓存目录，并阻止真实 httpx 传输：

```powershell
./.venv/Scripts/python.exe -B tools/test-proxy-contracts.py
```

只检查某一部分，可以追加 unittest 的模块、类或方法名：

```powershell
./.venv/Scripts/python.exe -B tools/test-proxy-contracts.py test_local_access test_excel_images
```

macOS 将 Python 路径换成 `./.venv/bin/python`。不要运行全仓库 pytest 自动发现，也不要搜索或修改生成的 `mutants/` 目录。GitHub Actions 使用同一个离线入口。

## 本地接口

默认地址为 `http://127.0.0.1:8000`。下面的模型接口也支持去掉 `/v1` 的路径。

| 接口 | 用途 |
| --- | --- |
| `GET /v1/models` | 获取本地模型列表；不要求先登录。 |
| `POST /v1/responses` | 文本、看图、流式回复及客户端工具调用。 |
| `POST /v1/responses/compact` | 生成供下一轮继续使用的上下文摘要。 |
| `POST /v1/images/generations` | 生成图片。 |
| `POST /v1/images/edits` | 编辑图片。 |

首页在 `/ui`，最近请求在 `/ui/requests`，根路径会跳转到首页。所有入口统一检查真实连接来源、Host 和浏览器来源；浏览器必须同源，本机原生客户端可以不带 Origin。服务入口关闭了代理转发头信任，不把 `X-Forwarded-For` 当作实际连接来源。

接口接收 JSON 对象。数组、数字、字符串、null 或损坏的 JSON 返回 400。损坏 JSON 的日志只保存路径、编码、长度等诊断信息，不打印正文片段或正文的十六进制值。

### 模型

| 模型 ID | 推理级别 |
| --- | --- |
| `gpt-6-astra-excel` | `medium`、`high`、`xhigh` |
| `gpt-5.6-luna-excel` | `low`、`medium`、`high`、`xhigh` |
| `gpt-5.6-terra-excel` | `low`、`medium`、`high`、`xhigh` |
| `gpt-5.6-sol-excel` | `low`、`medium`、`high`、`xhigh` |

Responses 请求接受省略 `-excel` 的别名。省略模型时使用 `gpt-5.6-sol-excel`；未知模型返回 400。模型是否真正可用仍由账号权限决定。

### 工具、历史与流式回复

客户端的工具定义会写入请求说明。Excel 返回的 `run_officejs` 在这里用来传递调用信息，代理把它还原成客户端声明的 function、custom 或 namespace 工具；代理不执行里面的代码。

整批工具必须全部校验成功后才会发给客户端，也只在这时写入重放缓存。未知工具、重复 ID 或未完成的调用不会先执行其中的有效部分。客户端设置 `parallel_tool_calls=false` 时，多个调用会被拒绝。

恢复历史时，缓存记录还必须与客户端给出的工具全名、JSON 参数或 custom 原文相符，不能仅凭相同的调用 ID 替换参数。JSON 的空白和键顺序不影响匹配；大整数和 custom 原文不会被改写。缓存不匹配时使用现有的历史重建路径，不借用另一条调用的内容。

流式等待每 15 秒保活。只有响应有真实 ID、输出项连续且全部完成，并以完整工具调用或明确最终回答结束时，才补全缺失的终止事件。仅有进度说明、半截参数或明确失败不会当作成功。开始生成后的传输错误不会自动重放整个请求。

请求需携带完整历史；`previous_response_id`、强制工具选择、结构化输出格式目前返回 400。推理摘要请求统一映射为 Excel 支持的 `auto`，没有上游摘要时不编造。上下文压缩失败时保留原历史。

### 图片

看图的内嵌格式限定为 PNG / JPEG / GIF / WebP；单张 20 MiB、单请求 20 张、解码后合计 32 MiB。消息和工具结果一起计入限制，完整检查通过后才上传消息附件。不同图片独立等待，同账号同图共享上传；工具结果保留原有内嵌内容。该检查不包含图片尺寸或像素内容解码。

生图和编辑均接收 JSON，使用 `gpt-image-2`，返回 PNG 的 `data[].b64_json`：

- `prompt` 必填；`n` 为 1–3，默认 1。
- `size`：`auto`、`1024x1024`、`1536x1024`、`1024x1536`、`1280x720`。
- `quality`：`auto`、`low`、`medium`、`high`；`background`：`auto` 或 `opaque`。
- 编辑使用 `images: [{"image_url": "data:image/png;base64,..."}]`，接受 1–3 张 PNG / JPEG / WebP，每张最多 20 MiB。代理转换成上游需要的 multipart，不自行下载远程图片。
- 不支持客户端直接提交 multipart、遮罩、透明背景、图片流式输出或非 PNG 输出。

托管 Codex 配置里的 `x-openai-actor-authorization = "excel-proxy"` 是图片工具接入标记，不是登录凭据。实际认证使用 Excel 会话。

## 设置和运行数据

Windows 的设置在 `%APPDATA%\ghcp_proxy`，会话、日志及历史在 `%LOCALAPPDATA%\ghcp_proxy`。macOS 状态在 `~/Library/Application Support/ghcp_proxy`，缓存在 `~/Library/Caches/ghcp_proxy`。源码整理不移动这些目录。

`excel-native-calls.sqlite3` 保存重放需要的工具参数，内存缓存最多 512 条，磁盘记录写入时清理超过 60 天未使用的项。全文调试记录默认关闭，但这个工具历史数据库仍会工作。旧目录名 `ghcp_proxy` 和 `GHCP_*` 环境变量继续保留，以兼容现有数据。

当前首页显示 API 费用估算。`/api/account-quota` 仍保留为可选接口，查询的是本机 Codex 登录账号的订阅额度，不是 Excel 额度；当前页面没有“检测额度”按钮。该功能早期参考了 `codex-quota-monitor`，见[实施记录](archive/plans/2026-09-25-quota-dashboard.md)。

| 环境变量 | 用途 |
| --- | --- |
| `GHCP_UPSTREAM_TIMEOUT_SECONDS` | 非流式请求超时，默认 300 秒。 |
| `GHCP_UPSTREAM_PROXY` | HTTP / HTTPS 上游代理。 |
| `GHCP_HTTP_PROXY`、`GHCP_HTTPS_PROXY` | 分协议设置代理。 |
| `GHCP_NO_PROXY` | 不经过代理的主机。 |
| `GHCP_UPSTREAM_TLS_VERIFY` | TLS 证书校验开关。 |

也会读取标准 `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY`。Excel 请求使用 HTTP/1.1。项目路径改变后，登录启动和终端快捷命令需在面板重新安装。
