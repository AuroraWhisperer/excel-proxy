# 账号额度、JSON 导入与无痕登录

[项目首页](../readme.zh-CN.md) · [English](../readme.md) · [文档目录](README.md)

在“用量与费用 → 账号额度”点击“导入账号 JSON”。支持单个账号、账号数组、Sub2API 的 `accounts` 导出，以及 Codex `auth.json` 的 `tokens` 对象。每次最多 50 个账号、文件不超过 1 MB。混入其他平台或无效账号时，整批导入失败，不会覆盖已保存账号。

必要字段是有效的 OpenAI 订阅 OAuth `access_token`。可选账号标识包括 `chatgpt_account_id` / `account_id`；也可以从 token 的未验证 JWT 声明提取路由提示，真正的权限由服务方验证。API Key 和只有 `refresh_token` 的文件不支持。不要把真实凭据提交到 Git 或发送给他人。

导入后自动查询第一个账号。用量页可见时每 15 秒更新本地显示，并按 60 秒间隔同步所选账号的额度；手动查询也共用服务端 60 秒缓存。其他账号通过选择器查看。凭据过期后重新导入或重新登录，不自动刷新或轮换 token。

## 官方无痕登录

点击“无痕登录添加”，在独立小窗口中的 OpenAI 官方页面输入账号、密码及 2FA 验证码。授权成功后自动添加并选中账号、查询额度。不需要把密码或验证码填入服务页面，也不要在对话中提供。

- 直接启动已安装的 Microsoft Edge 或 Chrome，不调用系统默认浏览器。每次使用全新的临时用户目录和 InPrivate / Incognito 模式，窗口为 560×780，不共享现有浏览器的登录、Cookie 或历史。没有可用浏览器时明确提示，不回退到默认浏览器。
- 使用授权码 + PKCE S256 和随机 state。回调只监听 `127.0.0.1` 的 1455 或 1457 端口；占用时不停止其他应用。10 分钟内完成，取消、超时、手动关闭或完成后清理本次窗口和临时目录。取消后可以重新开始。
- 只保存查询所需的 access token，沿用 Windows DPAPI 加密。不申请离线刷新权限，不持久化密码、2FA、refresh token、ID token，也不覆盖 Excel 或 Codex 的现有会话。登录状态 API 不返回授权 URL、state、PKCE verifier 或 token。
- 登录页面和额度接口均使用固定官方地址；授权码交换不跟随重定向。本机回调不记录带授权码的 URL，并清除地址栏中的回调参数。

此入口只负责添加余额查询账号，不切换服务实际使用的 Excel 会话。原有 Excel 会话捕获只是读取已有 WebView 会话，不能代替新的交互式官方授权，因此登录生命周期由独立的 `app/account_login.py` 管理，导入和余额逻辑仍复用原模块。

## 数据含义

- **账号表格**：名称、平台 / 类型、状态、用量窗口和操作集中在同一行；“明细”展开所选账号的本期用量，“管理”展开账号设置。
- **Credits**：仅在服务方实际返回余额或明确标记未设定上限时显示；缺失不占用一个空白余额区，明确返回 0 才显示 0。
- **余额折算**：在“估算说明与设置”中填写每 Credit 的美元单价。公式为余额 × 自填单价；不预设兑换率，不是实际账单或可提现金额，不给重置卡估值。留空保存可关闭折算。
- **查询与次数**：“查询”和“次数 N”均重新查询额度及可用重置卡数量，不消耗卡。只有点击“重置”或“使用重置卡”并二次确认后才会消耗一张，不会自动用卡。最近到期时间在有数据时显示。
- **额度窗口**：只显示服务方实际返回的 5 小时或 7 天窗口，进度条表示已用百分比，旁边显示重置时间；不是 Excel 专属余额。两个窗口重叠，不能相加。
- **周期美元估算**：本期服务参考成本 ÷ 已用比例，得出估算整期额度；再乘剩余比例得出估算剩余额度。沿用现有模型参考价，和 Credits 的自填兑换率无关；不是服务方账单或保证可用的美元余额。
- **下方本期用量 / API 费用估算**：跟随当前选择的账号和额度周期，复用上方周期估算的同一批请求。请求数、输入/缓存/输出 token、分项费用和模型明细一起切换，不再显示所有账号合并的月度数字。可选择 5 小时或 7 天窗口；两个窗口分别重置，不相加。
- **历史月度记录**：仍保留在原有用量记录和月度接口中，不因导入或重置删除；但不计入当前账号本期表，也不直接扣减账号 Credits。

## 周期与对话归属

每个账号、每个窗口独立保存当前周期及最近 20 条切换记录。周期以服务方 `reset_at` 为边界；只有倒计时时使用查询时间加 `reset_after_seconds`，容忍两秒取整抖动。初始统计起点为重置时间减窗口时长。

- **自然重置**：旧窗口已到期、服务方给出后续边界时建立新周期。到期但尚未成功同步时，已用比例显示 0，标注等待同步，不沿用旧美元估算。离线跨过多期只记录观测到的切换，不编造遗漏次数。
- **手动用卡**：以消费接口的成功回执和 `credit.redeemed_at` 为依据。返回实际重置窗口后，受影响窗口从新起点计费；即使结束时间没有变化也可切期。迟到回执升级已观测到的重置原因，不重复增加周期。返回重置 0 个窗口不新增用卡周期。
- **其他入口重置**：提前变化的窗口边界记为“外部窗口重置”，重新划分统计区间；不伪造本机未收到的消费回执。仅凭余额减少、卡过期或比例校正不认定用卡。
- **归零与重算**：已用比例为 0、没有可计价的本期有效样本、窗口到期或查询失败时，不计算整期额度；获得新的有效样本后自动重新估算，不除以零、不混入旧周期请求。费用统计对齐 Sub2API 的用量记录口径：失败或取消且未返回用量的尝试只保留在请求日志，不进入费用样本；失败但已返回用量的请求仍计入。成功请求缺少用量或参考价时仍保留缺失状态，只按已有可计价成本估算，不补造费用。窗口摘要移除“已计价 / 可能偏低”提示，统计项单行排列，空间不足时横向滚动；费用明细仍保留缺失项说明。

新请求按实际发往服务方的账号身份生成不可逆关联键，归档继续保留关联键，不记录原 token 或完整账号 ID。只使用同账号、起止时间完全位于当前周期且在本次额度查询前完成的请求。对话按这些请求的 `session_id` 去重；同一对话跨周期继续聊时，各期只计各自请求，不把整个对话累计成本搬到新周期。

旧版无账号关联键的记录不追溯猜测归属。跨越边界的单次请求无法准确拆分，不纳入周期估算。其他客户端消耗会进入服务方已用比例但不在本机请求成本中，因此会影响估算；页面明确标注为“本期服务参考成本”。

导入并选中新账号后，下方表只读取该账号的当前窗口，没有匹配请求就从 0 开始；不会继承此前所选账号的成本。自然重置或已确认的手动用卡建立新周期后，旧周期请求不再进入下方各项合计，即使仍在同一个对话里，也只计重置之后的请求。窗口到期但尚未同步、账号尚未查询或查询失败时显示等待状态，不拿旧账号/旧周期费用填充。首次导入已有用量的账号时，若本机确有同账号当前周期的可归属记录，会使用这些记录；不是人为清空服务方实际周期。

## 用卡失败与重试

消费前先原子保存唯一 `redeem_request_id`。回执丢失时显示“核对上次重置”，重试复用同一编号。确认成功后先保存回执，再查询额度；若查询失败，只刷新余额，不再次消费。新消费请求必须匹配用户确认时的额度快照，旧页面请求重放会被拒绝。请求期间同账号不能移除或重新导入。

查询失败会明确标记旧快照，并保留最后成功时间；重新导入凭据时清空旧账号快照，避免显示不匹配的余额。服务方接口可能受登录有效期、网络、访问权限或风控影响，查询失败不代表余额为零。

## 安全边界

账号独立保存在配置目录下的 `account-balances.dpapi`，使用当前 Windows 用户的 DPAPI 加密；不会修改 Excel 会话、Codex 登录文件或请求路由。不持久化 `refresh_token`、ID token、重置卡标识、原始 JSON 或原始服务方响应。浏览器仅收到脱敏展示数据，不使用 localStorage 保存凭据。

只接受本机、同源的 JSON 操作。查询对以下固定 HTTPS 地址执行 GET，禁止跟随重定向，也不采纳导入文件里的 URL 或网络转发地址：

```text
https://chatgpt.com/backend-api/wham/usage
https://chatgpt.com/backend-api/wham/rate-limit-reset-credits
```

只有经明确确认的用卡请求才向固定的 `https://chatgpt.com/backend-api/wham/rate-limit-reset-credits/consume` 发送 POST。周期、消费请求编号及脱敏回执与凭据一同加密持久化；公开 API 不返回消费请求编号或卡 ID。

移除账号会同时移除用量页和连接页中同一账号的本机登录信息；如果它是当前连接账号，服务会停止使用它，不会自动切换。该操作不删除服务方账号或导入文件原件。由于保存方式是 Windows DPAPI，不能直接将加密文件复制到其他 Windows 用户或其他系统使用。其他本地记录的范围见[隐私与本地数据](privacy.md)。

## 格式依据与验证

2026-09-26 核对 `Wei-Shaw/sub2api`，固定提交 `a3eb7ef302961cba716dc78b39b93b60c467db0e`：

- `backend/internal/handler/admin/account_data.go`：导入字段。
- `backend/internal/service/openai_quota_service.go`：额度结构、固定消费地址、幂等编号及嵌套成功回执。
- `backend/internal/service/openai_quota_reset_credits.go`：可用卡及到期信息。
- `backend/internal/service/openai_quota_auto_reset.go` / `openAIAutoResetCycleSeed`：按窗口长度和重置时间定义周期。
- `backend/internal/service/account_usage_service.go` / `codexWindowStatsStart`：按重置时间倒推本期统计起点，到期显示清零。
- `frontend/src/components/account/AccountUsageCell.vue`：`currentCost * 100 / utilization` 美元估算公式。

本项目不移植 Sub2API 的自动消耗卡策略，不假设未公开的官方 Credits 兑换率。

官方登录参考 `https://developers.openai.com/codex/auth/`，并核对 `openai/codex` 固定提交 `e72da2b53805894878023d01949a25a082e0a5cb` 的 `codex-rs/login/src/server.rs`（PKCE、回调端口、表单换码）和 `codex-rs/login/src/auth/manager.rs`（公开客户端 ID）。本实现按查询用途缩小授权 scope，不获取离线刷新凭据。
