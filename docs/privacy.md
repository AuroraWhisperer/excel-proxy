# 隐私与本地数据

[项目首页](../readme.zh-CN.md) · [English](../readme.md) · [文档目录](README.md)

本文说明服务会发送和保存哪些数据，以及不同登录方式的区别。账号操作步骤见[直接登录与多账号](direct-login.md)。

## 数据会发往哪里

| 操作 | 数据去向 |
| --- | --- |
| 对话、工具调用与看图 | 请求中的消息、工具定义、工具结果和图片会发往 OpenAI Excel/BPS 后端；消息图片通过 Excel 附件接口上传。 |
| 生成或编辑图片 | 提示词和编辑所需的图片发往 Excel 图片接口。 |
| 官方窗口登录 | 在 OpenAI 官方授权页面填写账号、密码和验证码，授权结果通过本机回调交给服务。 |
| 账号额度查询 | 使用所选账号的 access token 请求 ChatGPT 的额度与重置卡接口。 |
| 账号密码登录 | 账号和密码填入 OpenAI 官方页面；提供的 2FA 密钥会发送给第三方网站 2fa.fun 获取验证码。 |
| 首页导入 JSON | 文件交给本机服务解析，使用账号访问令牌请求 OpenAI Excel/BPS 接口；需要续期时，刷新令牌只发往固定的 OpenAI 官方授权接口。 |

**账号密码登录会将 2FA 密钥交给第三方。** 如需自行输入验证码，使用 **手动登录**，在官方页面完成验证。账密输入格式和自动填写行为见[登录说明](direct-login.md#账号密码登录与-json-文件)。

## 本地保存位置

| 平台 | 位置与内容 |
| --- | --- |
| Windows | `%APPDATA%\ghcp_proxy`：设置、直接登录账号和额度查询账号。 |
| Windows | `%LOCALAPPDATA%\ghcp_proxy`：导入的 Excel 会话、日志、用量记录和工具历史。 |
| macOS | `~/Library/Application Support/ghcp_proxy`：设置与历史；`~/Library/Caches/ghcp_proxy`：缓存。服务使用的 Excel 会话只留在内存。 |
| 两个平台 | 用户目录下的 `.codex`：Codex 接入配置、模型目录与原配置备份。 |

这些位置独立于项目源码目录。更新项目文件不会迁移上述数据。

### 凭据保存

Windows 的账号凭据和导入的 Excel 会话使用当前用户的 DPAPI 加密；加密文件不能直接复制给其他 Windows 用户或其他系统使用。此加密范围不包括普通日志、用量记录和工具历史。

- **连接账号**（直接登录或首页 JSON 导入）存于 `proxy-accounts.dpapi`，保存 access token、refresh token、有效期和已选择的账号，不保存原始 JSON 或 ID token。
- **额度查询账号**存于 `account-balances.dpapi`，只保存查询所需的 access token，不持久化 refresh token 或 ID token。
- 密码、验证码和自动登录用到的 2FA 密钥不写入账号文件或登录日志；浏览器页面只收到脱敏状态，不获得保存的 token。

直接登录成功后会把 access token 同步给额度查询账号库；续期与授权失败处理见[凭据与续期](direct-login.md#凭据与续期)。

## 请求日志与工具历史

**记录请求全文**默认关闭。开启后会记录后续请求的提示词和请求正文，用于排错；此前没有记录的全文无法补回来。排查完成后可以关闭开关，已经生成的记录不会因此自动删除。

关闭全文记录时，服务仍会保存请求用量、耗时、结果等运行记录，以及部分工具错误诊断。最近请求页最多展示 100 条，不等于本地只保存或统计 100 条。损坏 JSON 的解析错误日志只保存路径、编码和长度等诊断信息，不打印正文片段或正文的十六进制值。

为支持重启后继续工具任务，`excel-native-calls.sqlite3` 会保存工具调用历史与参数，其中可能包含文件名、命令和代码。它独立于全文记录开关；关闭全文记录并不等于本机完全不保存任务内容。缓存容量和保留规则见[开发说明](开发说明.md#设置和运行数据)。

## 移除账号与恢复配置

- 在连接页或用量页移除账号，会同时移除两个列表中同一账号的本机登录信息。移除当前使用的账号会停止使用它，不会自动切换到其他账号，也不会注销服务方账号。
- **清除缓存**清除的是导入的 Excel 会话，不等于移除直接登录账号，也不会让 Excel 加载项退出登录。Excel 仍登录时，可以再次读取。
- **恢复原配置**撤销 Codex 接入，需要重启 Codex；默认开启的 **关闭服务时恢复原配置**会在服务退出时执行恢复，下次启动时重新接入。

这些操作不等同于清空全部用量、日志或工具历史。导入账号 JSON 的原文件也不会因移除账号而删除。

## 本机访问范围

服务默认监听 `127.0.0.1:8000`，统一检查真实连接来源、Host 和浏览器来源，拒绝外部网页直接调用；不把 `X-Forwarded-For` 当作实际连接来源。

本地服务负责转发和转换工具调用，不执行模型生成的代码。文件读写与命令执行由 Codex 等客户端完成。
